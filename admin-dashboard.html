Управление отелями
Статусы отелей синхронизируются с порталом отеля и клиентским сайтом (при общем origin)
Комиссия отелей Corronyx
Каждый отель платит Corronyx 12% с каждой подтверждённой брони. Цикл расчёта — 10 дней, с переносом даты выходных на будни.
💳 Реквизиты Corronyx для получения комиссии от отелей
Эти реквизиты видит каждый отель в своём портале, в разделе «Выплаты». Заполняйте только то, что реально используете — hotel-portal.html покажет отелю только заполненные способы оплаты.
🪙 Криптовалюта — USDT в сети TON
Кошелёк TonKeeper (или любой другой TON-кошелёк). Не адрес TRC20/Tron — это другая сеть, TonKeeper такой адрес не примет.
📲 СБП (Система быстрых платежей)
Партнёр/отель переводит вручную по номеру телефона — автоматической проверки для СБП нет (нужна интеграция с банком), подтверждение только по скриншоту.

🎁 Заявки на вывод — крипта (не-резиденты РФ)
Реферал нажал «Забрать подарок» — баллы уже зарезервированы. Сгруппировано по стране, чтобы видеть, где реально активны рефералы. Отправьте USDT вручную через Tonkeeper и отметьте заявку(и) как выполненные — можно пачкой.
₽ Заявки на выплату — рубли (резиденты РФ)
Резидентам РФ крипта недоступна по закону (ст.14 259-ФЗ) — эта очередь отдельная, выплата на телефон (СБП) или карту. Пока без сервера — отправляете вручную через ЮMoney/банк, затем отмечаете заявку(и).

Афиша
Объявления о событиях от пользователей (afisha-portal.html) — разовая оплата за размещение, автоистечение через 21 день или по дате события.
👥 Условия оплаты организаторов
По умолчанию — обычная оплата. Можно освободить конкретного организатора от оплаты или дать скидку 50%.
📋 Шпаргалка КП
Готовые коммерческие предложения по каждому направлению. Откройте нужный пакет, скопируйте или отредактируйте текст перед отправкой.
💡 Цены для КП теперь редактируются в разделах партнёров: Агентства недвижимости, Турагентства, Экскурсии, Рестораны — там же, где сами партнёры. Здесь они только подставляются в текст автоматически.
Документы

Полный комплект юридических документов платформы. Каждый документ показан на том портале, к которому относится (см. колонку «Где отображается»). Версию и дату редакции нужно синхронизировать с реальным файлом при каждом обновлении.

🎁 Бесплатные рамки

Кому вы разрешили пользоваться золотой/бриллиантовой рамкой бесплатно — с ограничением по количеству одновременно активных рамок и/или по дате. Управление полностью ручное: система сама гасит рамку по истечении даты, но лимит и дату меняете только вы. Данные хранятся на сервере (не в этом браузере) — видны сразу отовсюду.

⏳ Льготный период просроченной подписки партнёра
Сколько дней карточка партнёра ещё видна гостям после просрочки оплаты, прежде чем спрятаться из публичного списка (сам партнёр её продолжает видеть в своём кабинете). По умолчанию — 7 дней.
