Заявки туроператоров
Проверьте номер в Едином федеральном реестре туроператоров и финансовое обеспечение перед одобрением (132-ФЗ). Одобренная заявка получает статус «active» и доступ к кабинету наравне с отелем; отклонённая — «rejected».
Комиссия отелей Corronyx
Каждый отель платит Corronyx 12% с каждой подтверждённой брони. Цикл расчёта — 10 дней, с переносом даты выходных на будни.
💳 Реквизиты Corronyx для получения комиссии от отелей
Эти реквизиты видит каждый отель в своём портале, в разделе «Выплаты». Заполняйте только то, что реально используете — hotel-portal.html покажет отелю только заполненные способы оплаты.
🪙 Криптовалюта — USDT в сети TON
Кошелёк TonKeeper (или любой другой TON-кошелёк). Не адрес TRC20/Tron — это другая сеть, TonKeeper такой адрес не примет.
📲 СБП (Система быстрых платежей)
Партнёр/отель переводит вручную по номеру телефона — автоматической проверки для СБП нет (нужна интеграция с банком), подтверждение только по скриншоту.

Тревоги ИИ-агента
Сообщения, на которые ИИ-агент отказался отвечать из-за подозрения на попытку взлома/обхода защиты. Обычные разговоры с агентом здесь не сохраняются — только эти случаи.
Резервная копия
Скачивает ВСЕ данные, которые сейчас хранятся в этом браузере (отели, брони, партнёры, рефералы, секретные ключи и т.д.), в один файл. Пригодится при переезде на новый домен — иначе на новом домене у браузера будет пустая память, как будто сайт открыли впервые.

Важно понимать: это резервная копия только ЭТОГО браузера на ЭТОМ устройстве. Она не «собирает» данные с телефонов и компьютеров других людей (гостей, отелей, партнёров) — у каждого из них данные хранятся отдельно, в их собственном браузере. Чтобы объединить все устройства в одну базу, нужен настоящий сервер (это отдельная, более крупная задача).
