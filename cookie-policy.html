платформы Corronyx

Редакция от 25.08.2026 (ПРОЕКТ — черновая версия для юридической проверки, не для публикации)

1. Файлы cookie не используются

1.1. Платформа Corronyx не использует файлы cookie ни в каком виде — ни собственные, ни сторонние, ни для аналитики, ни для персонализации, ни для рекламных целей.

1.2. Все настройки и данные, необходимые для работы Платформы (язык интерфейса, данные форм, сведения о бронированиях и размещении), сохраняются исключительно в локальном хранилище браузера (localStorage) на устройстве Пользователя. Подробнее — в Политике конфиденциальности (документ 2 реестра), раздел 3.2.

2. Сторонние сервисы

2.1. Отдельные функции Платформы (перевод интерфейса, отображение курса валют, генерация QR-кода для оплаты, определение координат при заполнении карточки) реализованы через обращение к сторонним публичным сервисам. Правила использования cookie этими сервисами (если они их используют на своей стороне) регулируются собственными политиками этих сервисов, а не настоящим документом.

3. Почему этот документ вообще существует

3.1. Настоящий документ присутствует в реестре юридических документов Платформы для полноты — чтобы явно и однозначно зафиксировать отсутствие cookie, а не оставлять этот вопрос без ответа для Пользователей и проверяющих органов.

4. Изменение политики

4.1. Если в будущем Платформа начнёт использовать файлы cookie (например, при подключении серверной инфраструктуры), настоящий документ будет полностью переработан заблаговременно до внедрения соответствующей функциональности, с уведомлением Пользователей.

ПРИМЕЧАНИЕ ДЛЯ АЛЕКСЕЯ: черновик для юридической проверки, не для публикации. Документ намеренно короткий — описывать нечего, cookie на сайте нет. Это лучше, чем пропускать пункт реестра совсем: явное "не используем" закрывает вопрос для пользователей и для проверяющих, тогда как отсутствие документа могло бы выглядеть как недосмотр. Юристу — короткая формальная проверка, специфических рисков нет.
